[업로드 및 첫 실행 순서]

1. 이 ZIP을 풀고, 안의 파일/폴더를 https://github.com/HSC-Class02/jh_skhynix 저장소의 기본 브랜치에 업로드합니다.
2. GitHub 저장소 Settings > Secrets and variables > Actions > New repository secret 에서
   Name: DART_API_KEY
   Secret: OpenDART에서 발급받은 40자리 인증키
   를 저장합니다.
3. GitHub 저장소에서 Add file > Create new file 을 선택합니다.
   파일명: .github/workflows/update-and-deploy.yml
   workflow_templates/update-and-deploy.yml 파일의 전체 내용을 붙여넣고 커밋합니다.
4. 같은 방법으로 파일명 .github/workflows/validate.yml 을 만들고
   workflow_templates/validate.yml 내용을 붙여넣고 커밋합니다.
5. Settings > Pages > Build and deployment > Source를 GitHub Actions로 설정합니다.
6. Actions 탭 > Update DART data and deploy dashboard > Run workflow 로 수동 실행합니다.
7. 성공하면 https://hsc-class02.github.io/jh_skhynix/ 에서 대시보드를 확인합니다.
8. 저장소 메인 화면 오른쪽 About > Edit repository details > Website에 위 Pages URL을 입력합니다.

주의:
- 이 ZIP은 업로드가 어려운 hidden 파일/폴더를 포함하지 않습니다. 그래서 workflow YAML은 workflow_templates 폴더의 비숨김 파일로 제공하며, 위 단계대로 .github/workflows/ 경로에 직접 생성해야 GitHub Actions가 실행됩니다.
- OpenDART 구조화 재무제표 API는 2015년 이후 자료를 제공하므로 2010~2014년은 공시 목록과 원문 링크를 수집합니다. 숫자가 없는 기간을 임의로 채우지 않습니다.
- workflow schedule은 매월 1일 00:20 UTC(한국시간 09:20)에 실행되도록 설정되어 있습니다.
